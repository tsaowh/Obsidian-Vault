	- 主觀預備合併
		- 主觀（訴訟 主體）
			- 當事人（原吿、被告）
		- 原吿方面 或 被告方面 列 先位、備位 
			- 若 法院認為 先位 當事人 請求有理由
				- 則 無須 對 備位 當事人之請求 為裁判
			- 若 法院認為 先位 當事人 請求無理由
				- 則 須 對 備位 當事人之請求 為裁判
		- 原吿方 預備合併
			- 原吿方面 列 先位、備位
				- 原吿
					- 先位
						- 甲
					- 備位
						- 乙
				- 被告
					- 丙
				- eg
					- 乙 原本對 丙 有一債權
					- 後來 乙 把這一 對丙的債權 讓與 甲
					- 甲 以此債權去告 丙
					- but 丙抗辯說：「乙讓與債權給甲這件事是無效的。」
					- 因 不確定真正的債權人 是甲 還是乙
					- 故 把 乙 預先放在後面當 備位原告，避免 甲乙間 債權讓與 無效，尚須由乙另訴請求
						- 須 乙 願意
							- 處分權主義
								- 程序之開始 由 當事人 主導決定
			- 原吿方 預備合併 較無爭議
				- 原吿方 依上述意願 自行決定
				- 即使  原吿地位不安定，亦應自負其責
					- 先位 有理由，不裁判 備位
					- 即 備位原吿 參與整個程序 卻得不到任何裁判
			- 若 先位 有理由，則 不裁判 備位
				- 先位之訴 有理由 為 備位之訴 解除條件
				- 即 先位之訴 判決確定 始為 其解除條件 成就
			- 若 先位 無理由，則 裁判 備位
				- 先位之訴 無理由 為 備位之訴 停止條件
			- 解除條件 vs 停止條件
				- 解除條件
					- 有效何時解除（有效 > 無效）
				- 停止條件
					- 無效何時停止（無效 > 有效）
