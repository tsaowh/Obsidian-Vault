	- 1
		- A 貨運公司 營業所 台中市 台中地院管轄
		- 甲 A公司負責人 住所地 彰化縣 彰化地院管轄
		- B公司 營業所 雲林縣 雲林地院管轄
		- 乙 B公司負責人 住所地 彰化縣 彰化地院管轄
		- 丙 住所地 彰化縣 彰化地院管轄
		- B公司 未給付 A公司 前年10月 貨運費用
		- 丙 未給付 A公司 前年12月 貨運費用
		- 甲 向 彰化地院 起訴 請求 
			- 共同被告 各別給付 A公司 積欠運費、遲延利息
		- 甲 起訴有無不法之處
		- 考點
			- 共同被告之管轄
			- 當事人適格之判斷標準
			- 共同訴訟之要件
		- ans
			- 彰化地院 有無 管轄權？
				- recall
					- 普通審判籍
						- 看 **被告在哪裡**
						- eg
							- 被告住高雄 → 高雄法院
					- 特別審判籍
						- 因 案件和某地 有特殊關聯
						- eg
							- 契約履行地、侵權行為地
						- 分兩情形
							- 單一被告
								- 22（管轄競合之效果）同一訴訟，數法院有管轄權者，原告得任向其中一法院起訴。
								- 普通審判籍 與 特別審判籍（除 10--1 專屬管轄 外）原則並存，依 22（管轄競合之效果）原告得任向其中一法院起訴
							- 共同被告（共同訴訟）
								- 20（共同訴訟之特別審判籍）共同訴訟之被告數人，其住所不在一法院管轄區域內者，各該住所地之法院俱有管轄權。但依第四條至前條規定有共同管轄法院者，由該法院管轄。
								- 有無 4～19「共同 特別審判籍」
									- 有 4～19「共同 特別審判籍」
										- 依 20（共同訴訟之特別審判籍）但書
										- 共同 特別審判籍 優先適用，排除 各被告 普通審判籍
									- 無 4～19「共同 特別審判籍」
										- 依 20（共同訴訟之特別審判籍）本文
										- 各被告 住所地法院 均取得 對整個共同訴訟的管轄權
											- 即 各普通審判籍 並存
										- 再依 22（管轄競合之效果）原告得任向其中一法院起訴
					- 合意管轄
						- 雙方事先約定第一審法院
						- eg
							- 契約約定「台北地院為第一審管轄法院」
					- 專屬管轄
						- 法律規定**只能由 特定法院管轄**
						- eg
							- 不動產物權訴訟 → 不動產所在地法院
				- 本案 無特別審判籍
					- 含 無 10--1 專屬管轄
				- 適用 20（共同訴訟之特別審判籍）本文
					- 共同被告
						- B公司
							- 雲林地院管轄
						- 丙
							- 彰化地院管轄
					- 故 雲林地院、彰化地院 皆有管轄權
			- 當事人適格之判斷標準？
				- 給付之訴 當事人適格 判斷標準
					- 依 原告 主張 形式判斷
					- 即 先不查 原告 表述是真是假，只看「照 原告 自己講的法律關係」，原告 是不是權利人、被告 是不是義務人
				- 因 甲 無 訴訟擔當 A公司
				- 故 甲 當事人不適格
				- 依 249--2（判決駁回）原告之訴，有下列各款情形之一者，法院得不經言詞辯論，逕以判決駁回之。但其情形可以補正者，審判長應定期間先命補正：
					- 249--2-1 當事人不適格或欠缺權利保護必要。
						- 此處 當事人不適格 之補正
							- 由 甲 改為 A公司
					- 249--2-2 依其所訴之事實，在法律上顯無理由。
				- 若 不補正，則 判決駁回
					- 此處 屬 訴訟判決
						- 非 請求無理由 之 實體判決
			- 共同訴訟之要件？
				- 53（共同訴訟之要件）
