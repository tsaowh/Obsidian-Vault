				- 190（合意停止之期間及次數之限制）合意停止訴訟程序之當事人，自陳明合意停止時起，如於**四個月**內不續行訴訟者，視為撤回其訴或上訴；續行訴訟而再以合意停止訴訟程序者，以一次為限。如再次陳明合意停止訴訟程序，不生合意停止訴訟之效力，法院得依職權續行訴訟；如兩造無正當理由仍遲誤言詞辯論期日者，視為撤回其訴或上訴。
					- 若 四個月內不續行訴訟
					- 則 視為 原吿 撤回其訴
						- 債權 有消滅時效
						- 起訴 會中斷時效
						- 撤回其訴 時效視為不中斷
							- 時效期間 仍自原起算點 繼續計算
							- 非「撤回後繼續算剩下的時間」；法律上是直接把 該中斷 當沒有發生過。
				- 實務上 合意停止 是為了 和解
				- 此題 聲請續行訴訟 為 被告 與 一般情形不同
					- 因 聲請續行訴訟 
						- 利於 原吿
						- 不利於 被告
					- 故 一般情形 原吿 聲請續行訴訟
				- 討論標的
					- 依 190（合意停止之期間及次數之限制）
						- 被告丙 聲請 續行訴訟 合法
						- 被告丁 聲請 續行訴訟 不合法
					- 則 被告丙 聲請之續行訴訟 效力是否及於 被告丁？
						- 因 共同被告 丙丁 為 普通共同訴訟
							- 實體法上關係 屬 不真正連帶債務
							- 程序法上關係 屬 普通共同訴訟
								- 適用 55（普通共同訴訟）
								- 共同訴訟人 獨立原則
						- 故 被告丙 聲請之續行訴訟 效力不及於 被告丁
							- 對 被告丁 而言，視為 原吿 撤回其訴
